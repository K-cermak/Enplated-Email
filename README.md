### FAQ

#### Is Enplated Email available for other languages or platforms (Node.js, Python, etc.)?
- Enplated Email currently works only with PHP. However, porting it to another language shouldn't be difficult.

#### When is Enplated Email not the best choice?
- Enplated Email is primarily designed as an engine for generating notification emails (account creation, password changes, support request responses, etc.).
- Using it for newsletters or online store order summaries can be more complicated. That said, it can be used for anything.
